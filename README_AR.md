# إعداد ورفع مشروع تسجيل الدخول

هذه نسخة Express تستخدم MongoDB Atlas لتخزين الحسابات. لا تحفظ كلمة المرور كنص عادي: تحفظ تجزئة scrypt مع ملح عشوائي، وتخزن الجلسة كرمز مجزّأ. أضيفت شاشة إنشاء حساب لأول استخدام.

## الملفات

- server.js: خادم Express ومسارات التسجيل والدخول والجلسات.
- index.html: الواجهة العربية.
- render.yaml: إعداد خدمة Render المجانية.
- .env.example: أسماء الإعدادات المطلوبة محليًا، بلا أسرار.

## 1. إعداد MongoDB Atlas

1. أنشئ حسابًا في MongoDB Atlas وسجّل الدخول.
2. أنشئ مشروعًا ثم Cluster مجانيًا. اختر أقرب منطقة متاحة إلى Frankfurt.
3. من Database Access أنشئ مستخدم قاعدة بيانات منفصلًا للمشروع. امنحه صلاحية readWrite على قاعدة haker_login فقط، واستخدم كلمة مرور قوية.
4. من Connect ثم Drivers اختر Node.js وانسخ رابط الاتصال. استبدل قيمة كلمة المرور في الرابط بكلمة مرور مستخدم قاعدة البيانات. لا تضع الرابط في GitHub أو في كود الصفحة.
5. اترك إعداد Network Access حتى تنشئ خدمة Render؛ ستضيف نطاقات الخروج الخاصة بها في الخطوة 4.

## 2. رفع الملفات إلى GitHub

1. أنشئ مستودعًا جديدًا في GitHub، ويفضل أن يكون Private.
2. ارفع محتويات مجلد haker-render-mongodb إلى جذر المستودع.
3. لا ترفع مجلد node_modules ولا ملف .env. ملف .gitignore يستبعدهما.
4. ارفع الملفات المطلوبة: index.html وserver.js وpackage.json وpackage-lock.json وrender.yaml وREADME_AR.md و.env.example و.gitignore.

## 3. إنشاء خدمة Render

1. افتح Render Dashboard واختر New ثم Blueprint.
2. اربط حساب GitHub واختر المستودع الذي رفعته.
3. سيتعرف Render على render.yaml. اختر تطبيق الإعداد.
4. عندما يطلب قيمة MONGODB_URI، أدخل رابط Atlas كاملًا في خانة السر داخل Render فقط.
5. اسم قاعدة البيانات مضبوط في الملف على haker_login. إعداد الخادم يستخدم المنفذ الذي يحدده Render تلقائيًا.
6. أكمل الإنشاء وانتظر نجاح Deploy. سيظهر رابط عام ينتهي بـ onrender.com.

لو أنشأت Web Service يدويًا بدل Blueprint، استخدم:
- Runtime: Node
- Build Command: npm ci
- Start Command: npm start
- Health Check Path: /health
- NODE_ENV: production
- MONGODB_URI: رابط Atlas، كقيمة سرية
- MONGODB_DB: haker_login

## 4. السماح لخدمة Render بالاتصال بـAtlas

1. افتح صفحة الخدمة في Render، ثم Connect ثم Outbound، وانسخ كل نطاقات IP المعروضة للمنطقة Frankfurt.
2. في Atlas افتح Security ثم Network Access ثم Add IP Address.
3. أضف كل نطاق CIDR نسخته من Render.
4. تجنب السماح العام 0.0.0.0/0؛ فهو يفتح اتصال قاعدة البيانات من أي عنوان على الإنترنت.
5. إذا تغيرت نطاقات الخروج في Render مستقبلًا، حدّث قائمة Atlas بها.

## 5. استخدام الموقع

1. افتح رابط onrender.com.
2. اختر إنشاء حساب وسجّل باسم مستخدم وكلمة مرور لا تقل عن 12 حرفًا.
3. سجّل الخروج ثم جرّب تسجيل الدخول بالحساب نفسه.
4. افحص قاعدة haker_login: ستجد المستخدمين في مجموعة users والجلسات في sessions. حقل كلمة المرور المحفوظ هو passwordHash، ولا يخزن النص الأصلي.

## ملاحظة عن الاستضافة المجانية

خدمة Render المجانية تدخل وضع السكون بعد 15 دقيقة بلا زيارات، والاستيقاظ عند الزيارة التالية يستغرق نحو دقيقة. كما أن Render قد يعيد تشغيل الخدمة، لذلك لا تحفظ قاعدة SQLite على قرص الخدمة المجانية؛ ملفاتها مؤقتة. MongoDB Atlas يخزن البيانات خارج الخدمة. لا تضمن الخطة المجانية بقاء الخادم نشطًا طوال اليوم؛ يلزم compute مدفوع إذا كان شرطك تشغيلًا دائمًا بلا نوم.
